
# AURA

### About Experience

**An experimental About Experience exploring identity, design, interaction, and digital storytelling.**

AURA is a creative web experiment built around the idea of turning a traditional About page into an interactive digital experience.

Instead of presenting information as a static profile, the experience uses typography, motion, visual systems, interaction, and structured storytelling to guide the visitor through the identity, process, and ideas behind the project.



## Experience

* Interactive hero section
* Experimental visual system
* Responsive layouts
* Scroll-based reveals
* Interactive service cards
* Process visualization
* Timeline experience
* Micro-interactions
* Custom cursor interaction
* Mobile-friendly design

## Built With

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
* CSS Animations
* Intersection Observer API

## Creative Direction

AURA explores how an About page can become more than a collection of information.

The interface is designed around a simple idea:

> **Identity is not only something you read. It is something you experience.**
